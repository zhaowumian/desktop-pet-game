# 桌面抓宠小游戏

基于 Electron 的桌面抓宠小游戏，宠物会在桌面上随机出现并奔跑，用鼠标抓住它们并拖入回收站获得分数！

## 功能特点

- 🐾 每 30-60 分钟随机生成一只小宠物
- 🏃 宠物会在桌面上随机方向奔跑
- 🖱️ 点击鼠标左键抓住宠物
- 🗑️ 拖拽宠物到右下角的回收站消除
- 📊 实时显示捕捉分数
- 🎨 透明窗口，不影响正常工作

## 安装和运行

```bash
# 安装依赖
npm install

# 启动游戏
npm start
```

## 游戏玩法

1. 等待宠物随机出现在桌面上
2. 用鼠标左键点击宠物抓住它
3. 拖拽宠物到右下角的回收站 🗑️
4. 成功回收获得 1 分！

## 宠物种类

- 🐱 小猫
- 🐕 小狗
- 🐰 兔子
- 🐹 仓鼠
- 🐦 小鸟
- 🐢 乌龟
